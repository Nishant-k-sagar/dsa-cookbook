# Contributing to DSA Cookbook

Hey there! Thanks for considering contributing to DSA Cookbook. Here's how you can help out.

## Getting Started

1. Fork the repo
2. Clone your fork locally
3. Install dependencies: `cd src/web && npm install`
4. Copy `.env.example` to `.env` and fill in your keys (see README.md for what's needed)
5. Start the dev server: `cd src/web && npm run dev`

## How to Contribute

### Found a Bug?
- Open an issue describing what went wrong
- Include steps to reproduce it
- If you can fix it, even better - submit a PR!


### Improving Existing Content?
- Fix typos, improve explanations, or add better examples
- Just make sure the C++ code actually works
- Submit a PR with a clear description of what you changed

## Pull Request Guidelines

1. Keep PRs focused - one thing at a time
2. Run `npm run lint` and `npm run build` before submitting
3. Write a clear description of what you changed and why
4. If you're fixing an issue, reference it in your PR

## Code Style

- TypeScript strict mode - no `any` types
- Functional components only
- No unnecessary comments - Only needed ones
- Follow the existing patterns in the codebase

## What We're NOT Looking For

- User accounts or authentication
- Progress tracking or social features
- Anything that turns this into a social platform

## Questions?

Open an issue if you have questions or suggestions. I'm pretty responsive.

Thanks for helping make DSA Cookbook better!
